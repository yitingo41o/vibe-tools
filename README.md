Nail Studio 穿戴甲配色模擬器

在實際製作或挑選穿戴甲之前，可以先在這裡試試看配色。選好甲型和長度、底色、款式（純色、漸層、法式），再加上亮片和貼飾，就能即時看到整組 10 片甲片排在甲片卡上的樣子。

覺得滿意的設計可以一鍵匯出成 PNG，用來當作配色參考、跟朋友討論款式，或是存下幾種方案互相比較。

使用方式

在「甲型」選擇形狀和長度。
在「底色」挑選色票，或用調色盤自訂顏色。
在「款式」切換純色、漸層或法式，並調整指尖的顏色和寬度。
在「亮片」調整密度、顏色和分布範圍。
在「貼飾」點一個圖示，再點甲片貼上，之後可以直接拖曳移動。
完成後按右上角的「匯出 PNG」下載設計圖。
